scRareRefine

一个 post-hoc（后处理）稀有细胞拯救模块：不改动 scANVI 的训练， 只在其输出的 latent embedding 与预测标签之上，对被漏判的稀有细胞执行 「可分性弃权 → 候选筛选 → 各向异性评分 → conformal 阈值校准 → 重标注」的拯救流程。
conformal rescue · distribution-free FFR ≤ α · inductive-safe
流程总览 交互演示 ① 原型与可分性 ② 候选筛选 ③ 各向异性评分 ④ Conformal 校准 ⑤ 重标注与弃权 数据隔离 设计动机 实验验证

①原型与可分性 来源：train 有标签子集

在 latent 空间用训练集有标签样本估计每个细胞类型的中心（原型），并量化稀有类是否「几何上可分」。

类原型

μc = mean{ z : label = c, 有标签 }

类内半径（稳健尺度）

rc = mediani∈c ‖zi − μc‖
类样本 < 3 时退化为 rc = 1.0，防止半径≈0 放大评分

可分性比率

sep = minc≠rare ‖μrare − μc‖⁄mean ‖zrare − μrare‖

分子=稀有原型到最近多数类原型的距离；分母=稀有簇平均半径。 sep 越大，稀有簇越"独立成团"。稀有标注<3 时强制 sep=0（触发弃权）。

两条先验阈值（数据集无关，不调参）： sep ≥ 1.3 → rescue 有效；sep < 1.3 → conformal 路径整体弃权。

对应代码：PrototypeRescuer.fit() · src/rescue.py:38–71

②候选筛选：各向同性 rank-1 闸门

只挑出「scANVI 没判成稀有」且「在普通欧氏距离下离稀有原型最近」的细胞作为候选。这是高精度的硬闸门。

cand(z) = [ base_pred(z) ≠ rare ]  ∧  [ argminc ‖z − μc‖ = rare ]

第一项排除已被正确识别的稀有细胞（无需处理）；第二项要求该细胞在几何上确实最像稀有类。 在演示面板②中，被黑色描边标出的就是候选——它们大多是落在橙色稀有簇里、却被 scANVI 判成灰色多数类的「漏网细胞」。

对应代码：PrototypeRescuer.isotropic_rank1() · src/rescue.py:89–96

③各向异性隶属度评分

给每个细胞一个连续的「稀有性」分数。关键是每个类用自己的半径 rc 归一化距离（各向同性 Mahalanobis 近似）， 让评分对各类尺度自适应，缓解边界数据集中相邻多数类「侵入」稀有类。

s(z) = softmaxc( − ‖z − μc‖ / rc )  的稀有类分量

对比 ③（各向异性，除以 rc）与朴素的各向同性 softmax(−d)：当稀有簇较紧致、相邻多数类较松散时， 归一化能把稀有细胞的分数顶上去、把多数类压下来，这正是消融实验中 V4（各向异性）在 borderline 数据集优于 V3（各向同性）的原因。

对应代码：PrototypeRescuer.rare_membership_score() · src/rescue.py:73–87

④Conformal 阈值校准 来源：val 非稀有细胞

不在小候选集上 grid-search 阈值（会过拟合、val→test 漂移），而是用 validation 集里数百~数千个非稀有细胞的分数， 取一个保守上分位作为阈值 τ，给出分布无关的假阳性率上界。

τ = s(k)，  k = ⌈(1 − α)(n + 1)⌉，  α = 0.01（固定）
n = val 非稀有细胞数；样本不足以保证时 τ = +∞（即不救）。这是有限样本 conformal 上分位。

它的自适应性是整套方法的精髓：

场景val 非稀有分数τ效果
高可分数据集普遍很低低真稀有分数远高于 τ → 召回不退化
边界数据集相邻多数类分数偏高自动抬升挡住会被误救的多数类 → 控制 FFR

对应代码：ConformalRescuer.calibrate() / _conformal_quantile() · src/rescue.py:462–477

⑤重标注与弃权安全网

同时满足「是候选」且「分数过阈」的细胞才改判为稀有类；其余一律保留 scANVI 原判。

fire(z) = cand(z) ∧ ( s(z) ≥ τ )  ⟹  label := rare
弃权安全网（最先执行）：若 sep < 1.3，跳过以上全部，直接返回 base_pred。 宁可不救，也不在不可分的场景制造大量误救——这保证了方法在难数据集上「无害」。

对应代码：ConformalRescuer.relabel() + 弃权判断 · src/rescue.py:479–486 / tools/comparison/compare_baselines.py:158

▸数据隔离（Inductive 合规）

每一个被「学习」出来的量都有唯一来源，test 标签只在最终评估时出现，代码层面严格隔离、无泄漏。

▸关键设计动机

为何 conformal 而非 grid-search 阈值？
旧方案（gate / marker / fusion）在 val 上 grid-search 阈值，存在 val→test 阈值漂移； conformal 用数百~数千个非稀有细胞校准，给出分布无关的 FFR ≤ α 上界，且没有任何 per-dataset 常量。
为何候选与评分解耦？
候选用各向同性 rank-1（强精度约束），评分用各向异性 softmax(−d/r)（尺度自适应）。 两者配合，在高可分与边界数据集上都稳健——这一点由消融实验逐组件验证。
